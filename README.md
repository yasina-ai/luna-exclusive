# Luna Exclusive — 超大尺度情趣性感个人站

基于 **Vue 3 + Vite + Vue Router + Tailwind CSS v4** 的成人内容创作者个人网站模板。

## 功能模块

| 模块 | 路径 | 说明 |
|------|------|------|
| 首页 | `/` | Hero + 最新写真 + 精选视频 + CTA |
| 关于我 | `/about` | 人设介绍 + 尺度声明 |
| 写真相册 | `/gallery` | 分类筛选、锁定预览、弹窗详情 |
| 视频专区 | `/videos` | 视频列表 + 会员锁定 |
| 会员订阅 | `/membership` | 三档会员方案 |
| 动态更新 | `/blog` | 博客/动态列表 |
| 定制服务 | `/custom` | 定制请求表单 |
| 商店 | `/shop` | 数字/实体商品 |
| 法律声明 | `/legal` | 年龄、版权、隐私、免责 |

## 特色

- 进入前强制 **18+ 年龄确认**（localStorage 记住）
- **多语言**：中文 / English（右上角切换，自动记忆）
- **多主题**：性感暗黑 / 优雅紫金 / 午夜深蓝 / 清透浅色（右上角切换）
- 响应式布局（移动端优先）
- 模拟数据完整，可直接替换为真实 API
- 会员锁定内容视觉提示

## 快速开始

```bash
cd adult-site
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`

## 技术栈

## 安全与合规说明（重要）

本仓库为**前端演示模板**，以下能力**必须**由真实后端/基础设施提供后才能用于生产：

- 服务端年龄与身份核验（不仅是 localStorage）
- 会员鉴权、签名 URL、水印、防盗链 / DRM
- 支付与退款的真实执行与对账
- CSRF、输入净化、速率限制、日志审计
- 按司法管辖区要求的 2257 记录与 DMCA 代理真实联系方式

当前已实现的前端加固（演示级）：

- robots / noindex / 安全响应头（Netlify）
- Cookie 同意条、§2257 与 DMCA 页面模板
- 年龄门需勾选确认 + 结构化 token（仍可被绕过）
- 分类筛选语言无关 ID、视频预览 timer 清理、图片 lazy
- 锁定内容展示收敛、表单防重复提交反馈
